# Artwork prepared for the proposed Nordic exercise redesign

These are prepared assets, not an activated UI change. No changes to the word-discovery game or any of its images are required.

Existing word-discovery illustrations remain read-only. `artwork-manifest.json` identifies exact reused cells for topic illustrations; vocabulary should prefer an exact match in the existing word catalog. Audio waves, microphone controls and progress indicators should be drawn in code.

The new `mission-scenes.webp` atlas supplies the ten human interactions missing from the existing bank. It has two columns and five rows, indexed row-major: transport, hospitality, construction, healthcare, cleaning, retail, office, studies, family and general conversation.

Generation: built-in image generation, using the existing home atlas only as a style reference. Prompt direction: premium semi-realistic Nordic watercolor/gouache vignettes, painterly detail, soft edges on warm ivory #fff8e9, muted petrol shadows, warm golden light, natural workplace interactions; no text or UI. Each scene is tied to its corresponding mission category.
